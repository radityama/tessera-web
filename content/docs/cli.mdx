## Search

Ranks components locally with deterministic lexical ranking. Scores and reasons print inline.

Syntax: `tessera search [options] <query>`

### Options

| Flag | Meaning |
| --- | --- |
| `--category <category>` | Filter by category. |
| `--framework <fw>` | `react` \| `vue` \| `svelte` \| `html` \| `other`. |
| `--source <name>` | Filter by source library. |
| `--motion <level>` | `none` \| `low` \| `medium` \| `high`. |
| `--limit <n>` | Max results, 1–50. Default 10. |
| `--json` | Stable JSON output for scripting. |
| `--registry <dir>` | Point at a different snapshot. |

### Example

```bash title="tessera search"
tessera search "dark technical terminal hero"
```

```text title="Output"
1. efferd/hero-1 — hero-1 (0.640)
   category: hero | source: efferd | frameworks: react
   motion: unknown | deps: 0 | license: unknown — verify upstream terms before reuse
   artifact: retrievable (shadcn-registry)
   why: exact category match: hero; matches query terms in name/description/tags; no required runtime dependencies
2. magicui/terminal — Terminal (0.628)
   category: terminal | source: magicui | frameworks: react
   motion: unknown | deps: 0 | license: MIT, redistribution permitted
   artifact: retrievable (shadcn-registry)
   why: matches aesthetics: terminal; no required runtime dependencies; known license (MIT)
3. aceternity/terminal — Terminal (0.588)
   category: terminal | source: aceternity | frameworks: react
   motion: unknown | deps: 0 | license: LicenseRef-Aceternity, redistribution restricted
   artifact: retrievable (shadcn-registry)
   why: matches aesthetics: terminal; no required runtime dependencies; known license (LicenseRef-Aceternity)
```

## Similar

Finds structural alternatives. Ranks by shared category, tags, motion level, and framework.

Syntax: `tessera similar [options] <source/slug>`

### Options

| Flag | Meaning |
| --- | --- |
| `--limit <n>` | Max results. Default 5. |
| `--json` | Stable JSON output. |
| `--registry <dir>` | Point at a different snapshot. |

### Example

```bash title="tessera similar"
tessera similar magicui/terminal
```

## Add

Prints a safe installation plan. Dry-run by default in v0.1 and never mutates the project. `--no-dry-run` is refused with an explanatory error.

Syntax: `tessera add [options] <source/slug>`

### Options

| Flag | Meaning |
| --- | --- |
| `--dry-run` | Only print the plan. Default true. |
| `--no-dry-run` | Attempt mutation. Refused in v0.1. |
| `--json` | Stable JSON output. |
| `--registry <dir>` | Point at a different snapshot. |

### Example

```bash title="tessera add"
tessera add magicui/terminal --dry-run
```

```text title="Output"
Plan for magicui/terminal (dry-run — no files changed):
- installation kind: command
- run: npx shadcn@latest add https://magicui.design/r/terminal.json
- Add through the shadcn CLI from the upstream registry URL, then adapt the copied source to your design tokens.
- required dependencies: none
- adapt to your design tokens before keeping (reuse composition, not identity).
```

## Fetch

Retrieves real upstream source files. The only network command. Files are written, never executed; collisions are skipped unless `--force` is passed; upstream paths escaping `--output` are rejected.

Syntax: `tessera fetch [options] <source/slug>`

### Options

| Flag | Meaning |
| --- | --- |
| `--dry-run` | Show what would be written without writing. |
| `--output <dir>` | Write files under this directory instead of printing. |
| `--force` | Overwrite existing files. Refused by default. |
| `--json` | Emit the artifact as JSON. |
| `--registry <dir>` | Point at a different snapshot. |

### Example

```bash title="tessera fetch"
tessera fetch magicui/terminal --dry-run
```

```text title="Output"
magicui/terminal — 1 file(s) from magicui
upstream: https://magicui.design/r/terminal.json
license: MIT, redistribution permitted
dependencies: none
registry dependencies: none
install: npx shadcn@latest add https://magicui.design/r/terminal.json

files:
  registry/magicui/terminal.tsx (7716 bytes)

Tessera wrote these files only because you asked. Nothing was installed or executed.
```

<Note role="warning" title="Under-reported dependencies">
  Not every component is fetchable: npm-shipped entries (HeroUI) and metadata-only records return a structured error. Provider-declared dependencies can under-report real imports — `magicui/terminal` imports `motion`, which its registry entry does not list.
</Note>

## MCP

Starts the MCP server. Speaks MCP over stdin/stdout (JSON-RPC 2.0). No flags besides `--registry`. Full protocol detail lives on the [MCP page](/docs/mcp).

Syntax: `tessera mcp [options]`

### Options

| Flag | Meaning |
| --- | --- |
| `--registry <dir>` | Point at a different snapshot. |

## Exit codes and JSON

Exit `0` on success, `1` on any handled error. Errors print as JSON on stderr:

```json title="Error shape"
{ "error": { "code": "...", "message": "..." } }
```

Every command accepts `--json` for scripting; search results carry id, name, source, category, visual tags, dependency count, motion, license status, score, and reasons.
